## Descripción

Aplicación móvil híbrida que solicita una cantidad en quetzales y la convierte a dólares con tasa fija **8 GTQ = 1 USD**.

Título de la página: **DivisApp 08001620**

## Cómo ejecutar

```bash
cd conversor-de-divisas
npm install
npx @ionic/cli serve
```
